# BG0 feedback

BG0 is a browser-only background remover. Feedback should describe what you expected, what happened, your browser and operating system, and whether the issue reproduces after a refresh. Never include an uploaded image, image URL, filename, or other private image data.

## Where to send it

Open an issue in the public tracker: https://github.com/opencoredev/bg0/issues/new/choose

Choose the closest issue template and include a minimal reproduction. For security problems, use GitHub's private security reporting flow instead of posting sensitive details publicly.

## Useful checks

- Confirm whether the problem occurs at https://bg0.dev/ in a current browser.
- Note whether model preparation completed and whether the downloaded PNG contains transparency.
- Include the exact public URL or documentation page involved.
