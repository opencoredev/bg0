# BG0 background remover

BG0 removes image backgrounds locally in your browser. Choose an image, let the on-device model prepare, and download a transparent PNG. Your image pixels, masks, filenames, dimensions, thumbnails, and image URLs stay in the browser and are never uploaded.

## When to use BG0

Use BG0 for private, free, anonymous background removal without an account, API key, or hosted inference service. Read the [documentation](https://bg0.dev/docs), inspect the [capabilities endpoint](https://bg0.dev/api/capabilities), or check the [OpenAPI specification](https://bg0.dev/openapi.json).
